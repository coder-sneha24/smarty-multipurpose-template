# 🚀 Smarty - Multipurpose Website Template

A modern and responsive multipurpose landing page template built using HTML5 and CSS3.  
This project showcases a professional UI layout with reusable sections including ecommerce, admin template, real estate, classifieds, and more.

---

//Features

- Modern Multipurpose Landing Page
- Responsive Layout Design
- Ecommerce Template Section
- Admin Dashboard Template Preview
- Real Estate Layout Section
- Classifieds Template Section
- Full Ajax Concept Section
- FAQ Section
- Reusable UI Components
- Font Awesome Icons Integration
- Clean and Structured Code

---

//Technologies Used

- HTML5
- CSS3
- Flexbox
- Font Awesome Icons
- Responsive Design Principles
